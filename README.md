## AI Utilisation

Coding Agents have been heavily used for the frontend part of the project. Backend sections were done by hand with some AI help for debugging purposes. The following models were used:

- GitHub Copilot Fusion/GPT 6 Luna
- Gemini 3.8 Flash
- Claude Sonnet 4.6

All the text in the project was fully written by hand. The original text can be found in the `Computational Geometry notes.pdf`.

Some of the code that has been edited by AI is marked using the 0RWX scale. Please visit [0rwx](https://0rwx.com/) for more information.
